# 산마루 농원 홈페이지

주소: https://sanmarufarm.github.io/

## 내용 고치는 법 (작물, 판매 시기, 문구, 전화번호 등)
1. 이 저장소에서 **`농원정보.yml`** 을 누릅니다.
2. 오른쪽 위 **연필 아이콘(Edit this file)** 을 누릅니다.
3. 내용을 고칩니다. 줄 앞의 띄어쓰기는 그대로 두세요.
4. 오른쪽 위 초록 버튼 **Commit changes…** → 다시 **Commit changes** 를 누릅니다.
5. 1~2분 뒤 홈페이지에 반영됩니다. 위쪽 **Actions** 탭에서 초록 체크(✓)가 뜨면 완료입니다.

빨간 X가 뜨면 Actions 탭에서 해당 항목을 눌러 보세요. "홈페이지 만들기" 단계에 무엇이 틀렸는지 한국어로 적혀 있습니다. 고치는 동안 홈페이지는 이전 모습 그대로 유지됩니다.

## 사진 바꾸는 법
- **같은 이름으로 바꾸기**: `images` 폴더 → **Add file → Upload files** → 기존과 똑같은 파일 이름의 사진을 끌어다 놓고 Commit.
- **새 이름으로 추가하기**: 위처럼 올린 뒤, `농원정보.yml` 에서 그 사진을 쓸 곳의 파일 이름을 바꿔 줍니다.
- 휴대폰 사진은 용량이 크니 가로 1600px 정도로 줄여서 올리면 홈페이지가 빨라집니다. 파일 이름은 영어·숫자로 지어 주세요.

## 되돌리기
위쪽 **History(시계 아이콘)** 에서 예전 기록을 볼 수 있습니다. 잘못 고쳤으면 예전 내용을 복사해 다시 저장하면 됩니다.

## 파일 설명 (고칠 일 거의 없음)
- `template/` : 홈페이지 모양(디자인). 
- `build.py` : `농원정보.yml` 을 읽어 홈페이지를 만드는 프로그램.
- `.github/workflows/deploy.yml` : 저장할 때마다 자동으로 홈페이지를 다시 만들어 올리는 설정. 매달 2일에도 한 번 자동 갱신합니다.
